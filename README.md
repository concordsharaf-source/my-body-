# جسمي | Jismi — موسوعة تشريح تفاعلية

> اكتشف جسمك 🧍

تطبيق ويب تقدّمي (PWA) عربي بالكامل (RTL) لموسوعة تشريحية تفاعلية: نموذج جسم بشري متعدد الطبقات، 12 جهازًا حيويًا، أكثر من 90 عضوًا ببيانات تعليمية موثقة، جولات متحركة، اختبارات، بطاقات تعليمية، وبحث محلي — **يعمل دون إنترنت بالكامل** بدون حسابات وبدون خادم.

## المزايا

- **النموذج التشريحي التفاعلي**: تكبير/تحريك/قرص (Pinch)، 14 طبقة قابلة للتبديل، وضع "تشريح طبقي" بالتقشير التدريجي، ووضع "أجهزة" بعزل جهاز مع أسماء وعدّاد أجزاء.
- **نموحان حسب الجنس** (ذكر/أنثى) بأعضاء تناسلية وفروق تشريحية مختلفة، بأسلوب طبي محترم.
- **93 عضوًا** ببيانات كاملة: 3 مستويات معرفية (مبسط/تعليمي/متقدم)، الوظيفة، الموقع، آلية العمل، الأجزاء، علاقات تفاعلية (شبكة معرفة)، حقائق، مصطلحات، أسئلة شائعة، "ماذا يحدث إذا توقف؟"، مصادر ومراجعة.
- **12 جهازًا**: عصبي، دوري، تنفسي، هضمي، بولي، عظمي، عضلي، تناسلي (ذكر/أنثى)، لمفاوي، غدد صماء، حسّي.
- **جولات متحركة**: رحلة قطرة الدم، رحلة الطعام، رحلة الهواء + "رحلة داخل الجسم" الموجهة (12 خطوة).
- **اختبارات**: بنك أسئلة مولّد (اختيار من متعدد/صواب وخطأ/أين يوجد/أي جهاز) مع حفظ أفضل نتيجة.
- **بطاقات تعليمية**: "ما اسم هذا العضو؟" مع كشف الوجه.
- **بحث محلي** بالعربية والإنجليزية والمصطلحات الطبية والاستفسارات المفهومية ("عضو تنقية الدم" → الكليتان).
- **مفضلتي + تعلمي**: متابعة تقدمك محليًا (localStorage) بدون حسابات.
- **PWA**: يعمل دون إنترنت، قابل للتثبيت، أيقونات، manifest عربي RTL.
- **إمكانية الوصول**: قارئات شاشة، لوحة مفاتيح، أهداف لمس كبيرة، خيار تقليل الحركة، تحجيم خط، وضع داكن/فاتح/نظام.
- **السلامة**: محتوى تعليمي بحت — لا تشخيص، لا أمراض، وإخلاء مسؤولية طبي واضح.

## التشغيل

```bash
npm install
npm run dev      # تطوير على http://localhost:5173
npm run build    # فحص TypeScript + بناء PWA إلى dist/
npm run preview  # معاينة النسخة المبنية
```

توليد الأيقونات من الشعار:

```bash
node scripts/make-icons.mjs
```

إعادة حساب مربّعات تقريب/تسمية الأعضاء من هندسة الأشكال (بعد تعديل `shapes.ts`):

```bash
node scripts/rebox.mjs
```

اختبار الدخان (يتطلب `playwright`):

```bash
node scripts/smoke.mjs   # مع BASE=http://127.0.0.1:4173
```

## البنية

```
src/
├── data/               # المحتوى: منفصل تمامًا عن الواجهة
│   ├── types.ts        # الأنواع (Organ, System, LayerDef, ...)
│   ├── systems.ts      # 12 جهازًا
│   ├── layers.ts       # 14 طبقة + خطوات التشريح الطبقي
│   ├── organs/         # ملفات الأعضاء (12 ملفًا حسب الجهاز)
│   ├── glossary.ts     # 32 مصطلحًا طبيًا
│   ├── journeys.ts     # رحلة الجسم + جولات الدم/الطعام/الهواء
│   ├── compare.ts      # فروق ذكر/أنثى
│   └── quizzes.ts      # بنك الأسئلة
├── components/
│   ├── BodyModel/      # النموذج: shapes.ts (الهندسة) + BodyModel.tsx (التفاعل)
│   ├── OrganCard.tsx   # بطاقة العضو (ملخص + تفاصيل + مشاركة + مفضلة)
│   ├── MiniOrgan.tsx   # عضو معزول بقص viewBox (البطاقات التعليمية)
│   ├── LayerPanel.tsx  # لوحة الطبقات + شريط التقشير
│   └── ...             # BottomNav, SystemsGrid, SexSelect
├── pages/              # 15 صفحة (كلها lazy-loaded)
├── lib/                # search.ts (بحث محلي)، quiz.ts (مولد الأسئلة)، pwa.ts
├── store/              # zustand persist (تفضيلات المستخدم + بيانات التعلم)
└── i18n/ar.ts          # كل نصوص الواجهة
```

**إضافة عضو جديد**: أضف كائن `Organ` في الملف المناسب تحت `src/data/organs/` — سيظهر تلقائيًا في النموذج (إن وُجد شكل له في `shapes.ts`) والبحث والأنظمة والاختبارات. لا حاجة لتعديل أي مكون.

## التقنيات

React 18 · TypeScript · Vite 5 · zustand · react-router (lazy routes) · vite-plugin-pwa (Workbox) — بدون أي خادم أو اعتماديات بيانات خارجية. البنية جاهزة لاحقًا لـ Capacitor (أندرويد) و3D/audio/i18n إن طُلبت.

## الإخلاء

محتوى «جسمي» تعليمي مبسّط، ولا يُعد بديلًا عن الاستشارة الطبية.
